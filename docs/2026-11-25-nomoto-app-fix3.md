## 四个界面行为（批准口径）

1. **产物下载反馈**（surface `artifacts-reader`）
   - 点「下载」后页面立即给出已开始反馈；下载完成页面内有明确成功提示（系统通知之外双保险）。
   - 真实失败（未绑定/令牌失效/网络）就地显示可读原因与重试，不再静默。
2. **HTML 预览可打开**（surface `artifacts-reader`）
   - 产物阅读页点「预览」，设计稿 HTML 在沙箱预览框内正常显示。
   - 安全不降级：一次性 60 秒票据用一次即焚、内容安全策略不变、预览脚本仍碰不到控制台数据。
3. **总览串行链可打开**（surface `core-projects-serial`）
   - 「项目 DAG 进度」里每条串行链可点开详情：节点清单（业务标题/当前环节/百分比/一句话进展）与整体进度。
   - 无活跃链时有如实空态；渲染正确性由种子链测试数据验证，不依赖真机碰巧有活跃链。
4. **折叠卡片逐张展开**（surface `collapsible-cards`）
   - 每张被折叠的静态信息卡片右下角各有「展开/收起」，点击只展开当前这张。
   - 跨刷新展开状态保留；按需加载内容与失败重试、交互内容排除等既有行为不变。
