# 移动端与设备授权管理后台 PRD

- 文档状态：待确认（v1.0）
- 日期：2026-11-18
- 适用项目：`/Volumes/Storage/auto调度`
- 产品用户：控制台所有者
- 关联设计稿：`docs/design/2026-11-17-mobile-app/`
- 关联契约：`AGENTS.md`、`docs/scheduling-contract.md`

## 1. 背景

当前 Autoloop 控制台只能在桌面浏览器中使用，用户离开电脑后无法及时处理待办、查看项目进展或阅读产物。移动端没有独立前端，也没有设备授权管理能力；用户无法在手机上安全地接收通知、回复待办或查看交付结果。

本 PRD 定义一个独立的移动端前端，并复用现有后端服务；同时在网页控制台中新增设备授权管理后台，用于绑定和解除设备授权。移动端与网页管理后台共用同一后端，不新建第二套业务状态。

## 2. 目标

1. 在任意移动网络或外部 Wi-Fi 下，手机可直接、安全地使用控制台核心能力。
2. 手机端可完成总览、项目 DAG、会话、待办、规则、轮次和产物浏览。
3. 所有“待我处理”事项与节点成功完成均能通过系统通知触达手机。
4. 用户可在手机上直接完成待办回答，支持选项、文字和语音输入。
5. 网页控制台提供设备授权管理后台，支持绑定新设备、查看已绑定设备、解除授权。
6. 设计与交互适配直板手机与折叠屏，并跟随系统字体大小。
7. 移动端为独立前端，不把网页控制台简单缩小后复用。

## 3. 非目标

1. 不包含网页控制台的“运行环境”与“宿主平台开通”改造，另立 PRD。
2. 不修改 Autoloop Hub 上游核心。
3. 不新建第二套执行、恢复或状态系统。
4. 不在移动端承担设备授权管理后台职责；移动端不能解除其他设备授权。
5. 不做自定义语音播报；通知使用手机系统能力。
6. 不为高风险操作增加额外生物识别或密码门槛；仅打开 App 与锁屏直复需要验证。
7. 不做 HarmonyOS NEXT 原生包；首版以 Android APK 覆盖当前旧版鸿蒙设备，折叠屏布局作为设计基线。

## 4. 用户与场景

### 4.1 目标用户

- 控制台所有者，需要在离开电脑时继续掌控自动化任务。
- 关注项目进展、待办处理、会话产物和节点完成情况。
- 希望通过手机系统通知及时获知需要本人决策的事项。

### 4.2 典型场景

1. 用户在外出时收到待办通知，直接在锁屏或进入 App 后完成回答。
2. 用户在通勤路上查看项目 DAG 进度、节点状态和产物文档。
3. 用户在多台手机上同时使用控制台，任意一台提交后其他设备同步状态。
4. 用户在电脑上打开网页管理后台，绑定新手机或解除丢失设备授权。
5. 用户调整系统字体大小后，App 内所有正文、选项、输入框和产物文档随之自然重排。

## 5. 产品范围

### 5.1 移动端 App

移动端是独立前端，复用现有后端服务，不复制业务状态。

核心页面与能力：

1. **总览**：运行、重试、完成、待办、项目 DAG 进度与最近动态。
2. **项目 DAG**：环形进度图、波次节点、槽位、执行 Agent、模型、费用、Token、证据与合并提交。
3. **会话管理**：类型筛选、搜索、当前会话、已归档与历史。
4. **会话内待回答组**：Agent 连续提出多个问题时，以一组待回答事项嵌入会话，支持逐项选择、文字和语音输入，保留上下文与进度。
5. **产物浏览**：全局产物管理页 + 会话内直接打开；显示所属会话、当前任务与路径。
6. **调度规则**：运行、暂停、恢复、编辑，保持现有网页能力。
7. **执行轮次**：状态追踪、结果摘要、会话链接与停止。
8. **待我处理**：独立事项列表，保留决策上下文，支持选项、文字和语音回答。
9. **系统通知**：待办与节点完成通知，支持锁屏直复与进入 App 两条路径。
10. **设备与偏好**：多设备绑定、通知偏好、系统字体、生物识别设置。

### 5.2 网页管理后台

网页控制台新增设备授权管理后台，作为现有控制台的一个管理区域，不新建独立系统。

能力：

1. **绑定新设备**
   - 在网页管理后台生成一次性二维码。
   - 手机扫码并确认后完成绑定。
   - 绑定后设备获得访问与通知资格。
2. **查看已绑定设备**
   - 显示设备名称、系统、最近活跃时间、当前状态。
   - 支持多设备同时绑定。
3. **解除设备授权**
   - 仅网页管理后台可解除任意设备授权。
   - 解除后该设备立即失去访问与通知资格。
   - 手机端不能解除其他设备授权。
4. **审计记录**
   - 记录绑定、解除、设备重命名等关键操作。
   - 记录操作来源、时间与结果。

### 5.3 通知与安全

1. **通知范围**
   - 每项“待我处理”对应一条独立系统通知。
   - 每个节点成功完成对应一条独立系统通知。
   - 普通失败、自动重试、调度自愈不通知；若形成待我处理项，只发送该待办通知。
2. **通知路径**
   - 点击通知进入 App，定位到对应事项。
   - 或在系统通知内直接选择、文字回复。
3. **生物识别**
   - 打开 App 需要系统指纹或人脸验证。
   - 锁屏直复需要系统生物识别。
   - 进入 App 后，高风险操作不额外增加验证门槛。
4. **多设备**
   - 所有已绑定设备可同时接收通知。
   - 任意一台设备提交后，其他设备同步状态。
   - 设备丢失时，可在网页管理后台解除该设备授权，不影响其他设备。
5. **锁屏显示**
   - 锁屏通知显示项目名称、待办摘要和节点完成详情。
   - 用户可按系统通知偏好调整声音、振动与锁屏展示。

## 6. 关键交互与信息架构

### 6.1 全局项目筛选

- 项目是全局一级筛选，不是各页面局部筛选。
- 总览、规则、会话、轮次、待办、DAG 与产物均显示当前项目，可切换“全部／具体项目”。
- 切换后所有 Tab 同步生效，列表内容正确过滤。
- 项目筛选不改变会话内上下文；进入会话后仍显示该会话所属项目。

### 6.2 项目 DAG

- 使用环形进度图，不用串行链条表示项目进度。
- 环形分段表示节点，颜色对应波次，深浅表示状态。
- 中心显示总进度。
- 配套信息包括：波次节点、槽位、分支、执行 Agent、模型、费用／Token、证据、合并提交、是否等待下游启动。
- 点击节点可查看节点契约、输入、输出、异常行为与验收示例。

### 6.3 会话与待回答组

- 会话列表保留类型筛选、搜索、当前会话与已归档与历史。
- Agent 回复中连续提出多个问题时，以“待回答组”嵌入会话：
  - 保留原话与背景。
  - 显示总数、已答数和进度轨。
  - 每次聚焦一道题，已答题折叠保留，可展开回看。
  - 支持选项、文字与语音输入。
  - 提交后进入下一未答题。
  - 未答数量在会话顶部持续可见。
- 浏览产物、切换会话、旋转或折叠后，未答进度、草稿与滚动位置不丢失。

### 6.4 产物浏览

- 产物有双入口：
  1. 全局产物管理页。
  2. 会话流内“本会话产物”。
- 每个产物显示所属会话、当前任务与路径。
- 手机：会话 → 全屏产物列表 → 全屏阅读 → 逐级返回。
- 折叠屏：左侧文件列表、右侧阅读；选择文件只更新右侧，不让整个会话跳页。
- 产物只读；系统分享导出只读副本，不在手机端改写目标项目。

### 6.5 已归档会话

- 默认折叠。
- 展开后显示数量、项目、转录条数与停止原因。
- “查看”进入只读转录。
- “继续调度”创建新会话并注入最近 10 轮转录，原记录保留。

### 6.6 通知直复

- 待办通知支持两条路径：
  1. 进入 App 定位原会话问题。
  2. 在系统通知内直接选择或文字回复。
- 节点完成通知点击后进入对应节点交付详情。
- 已处理或失效事项不重复提交；失败时题目、选项和草稿保留。
- 通知与 App 内状态同步更新，避免误点过期事项。

### 6.7 语音输入

- 覆盖所有会话输入框。
- 点击麦克风开始说话，实时转为可编辑文字。
- 可手动修改、追加语音或撤销。
- 不因停顿自动发送。
- 未授权、识别失败或无网络时，可直接使用键盘。

### 6.8 字体与无障碍

- 字体大小跟随手机系统设置。
- 使用原生字体度量，不以网页缩放代替。
- 放大后采用换行、容器增高和纵向滚动。
- 不截断、不遮挡、不把正文强制压成横向滚动。
- 图标视觉保持轻巧，但交互热区扩展至约 44–48 dp。
- 整卡选项有清晰按压、选中和禁用状态。
- 适配安全区、系统返回、键盘升降、横竖屏与折叠／展开状态连续性。

## 7. 数据与权限

1. 移动端与网页管理后台共用同一后端服务。
2. 不新建第二套业务状态；控制台仍是集成入口，Hub 是执行本体。
3. 设备授权、绑定与解除作为控制台管理能力，不进入目标项目工作区。
4. 网页管理后台与移动端共用设备授权状态。
5. 网页管理后台可解除任意设备授权；移动端只能查看自身绑定信息。
6. 所有写操作沿用现有安全校验、路由允许列表与错误转换。
7. 不把 Autoloop 密钥、设备凭证或用户个人数据写入浏览器、截图或测试快照。
8. 真实设备绑定、通知供应商配置与真机验证属于实现阶段，不在本 PRD 内执行。

## 8. 成功标准

1. 手机在任意移动网络或外部 Wi-Fi 下可直接使用核心能力。
2. 待办与节点完成通知可稳定触达，且与 App 内状态一致。
3. 用户可在手机上完成待办回答，不丢失上下文、草稿或滚动位置。
4. 项目筛选为全局一级筛选，所有主要 Tab 同步生效。
5. 项目 DAG 使用环形进度图，信息与现有基线一一对应。
6. 会话内可同时看到待回答组、产物与归档历史。
7. 产物可从会话直接打开，并能返回原会话。
8. 系统字体放大到 160% 时，无截断、遮挡或横向溢出。
9. 网页管理后台可绑定、查看和解除设备授权，且移动端不能越权解除其他设备。
10. 多设备同时绑定时，任意一台提交后其他设备同步更新。

## 9. 验收示例

1. 在网页管理后台生成二维码，用手机扫码绑定成功。
2. 在手机上打开 App，通过生物识别后查看总览、DAG、会话、待办与产物。
3. 收到一条待办通知，在锁屏直接回复，随后 App 内状态同步更新。
4. 在会话中打开一个 Markdown 产物，返回会话后草稿与滚动位置保留。
5. 切换全局项目筛选为具体项目，总览、规则、会话、轮次、待办、DAG 与产物同步过滤。
6. 将系统字体调整到 160%，长文自然换行，无截断或遮挡。
7. 在网页管理后台解除一台设备授权，该设备立即失去访问与通知资格。
8. 两台已绑定手机同时收到同一待办通知，任意一台提交后另一台同步更新。

## 10. 分波次交付建议

1. **Wave 1**
   - 移动端核心页面与安全连接。
   - 待办通知与锁屏直复。
   - 网页管理后台设备绑定与解除授权。
2. **Wave 2**
   - 会话内待回答组与语音输入。
   - 产物双入口与折叠屏双栏。                                                                                                                                                                                                                                                                                         
3. **Wave 3**
   - 项目 DAG 环形图细节与节点交付。
   - 系统字体与触控热区全面打磨。
   - 多设备状态同步与审计完善。
