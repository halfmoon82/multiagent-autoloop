## 2. 本稿确认范围

原型覆盖以下完整产品页面与情境，不以“实施分波”为由删减设计：

1. 总览：运行、重试、完成、待办、项目进度与最近动态。
2. 会话内待回答组：Agent 一次提出多个问题时的逐项选择、文字、语音和回看。
3. 会话产物：数量、搜索、过滤、路径和最近更新。
4. 产物阅读：Markdown、源码、HTML 沙箱、只读分享与返回。
5. 会话列表：类型筛选、搜索、状态、已归档与历史、只读查看和恢复。
6. 调度规则与规则表单。
7. 执行轮次。
8. 待我处理列表。
9. 项目 DAG 与节点完成入口。
10. 执行授权。
11. 新建会话与语音首轮输入。
12. 系统锁屏通知、通知直复与节点完成通知。
13. 打开 App／锁屏直复的生物识别。
14. 多设备绑定、通知偏好与系统字体。

## 3. 2026-11-18 返工修正

1. **项目筛选升为全局一级状态**：所有主要 Tab 均显示当前项目（默认“全部”），点击后打开项目选择面板；总览、规则、会话、轮次、待办、DAG 与产物使用同一筛选状态，切换后列表内容同步变化。
2. **项目进度改为 DAG 环形图基线**：环形分段表示节点，颜色对应波次、深浅对应状态；中心显示总进度；配套波次节点、槽位、分支、执行 Agent、模型、费用／Token、证据、合并提交和“PR 合并后下游才启动”。不再用串行链条表达项目进度。
3. **会话 Tab 补齐“已归档与历史”**：默认折叠，展开后显示数量、项目、转录条数和停止原因；“查看”进入只读转录，“继续调度”创建新会话并注入最近 10 轮转录，原记录保留。
4. **规则与待办交互保持现有网页能力**：规则仅提供运行／暂停／恢复／编辑；待办在卡片内提供选项回答、文字回答与结案，不虚构“进入原始会话”能力。轮次页保留现有“会话链接”能力。
5. **产物双入口**：既有全局产物管理页，也在会话流内显示“本会话产物”；每个产物标明来自当前会话与当前任务，点击直接打开只读预览，返回回到原会话且恢复草稿、滚动和待回答进度。

## 3. 核心交互决定

### 3.1 Agent 多问题待回答组

- 多个问题作为**同一 Agent 回复下的一组待回答事项**嵌入会话，不跳转成孤立表单。
- 组头展示总数、已答数和进度轨；每次聚焦一道题，已答卡折叠保留，可展开只读回看。
- 保留 Agent 原话与“查看背景”入口；点击通知后定位到该组对应的问题。
- 选项使用整卡热区，选择后再提交，避免触摸误发；提交后进入下一道未答题。
- 文字题支持键盘和语音转写；语音结果可编辑，不因停顿自动发送。
- 每道题独立提交后端并保留原会话上下文，已成功回答的不重复提交；失败时题目、选项和草稿保留。
- 会话顶部持续显示未答数量；浏览产物、切换会话、旋转或折叠后，未答进度、草稿与滚动位置不丢失。
- “退回调度处理”保留现有能力，不代替用户作答。

### 3.2 产物浏览与阅读

- 手机：会话 → 全屏产物列表 → 全屏阅读 → 逐级返回；返回恢复文件列表位置和会话状态。
- 折叠展开：左侧文件列表、右侧阅读；选择文件只更新右侧，不让整个会话跳页。
- 文件卡展示类型、文件名、项目相对路径、大小和更新时间；长文件名省略，但完整名称可在阅读页查看。
- Markdown 默认阅读视图，可切源码；HTML 使用沙箱预览；代码段允许局部横滑，页面本身不横向溢出。
- 产物只读；系统分享导出的是只读副本，不在手机端直接改写目标项目。

### 3.3 系统通知与设备安全

- 每项“待我处理”一条独立通知，不按项目合并；每个成功节点也一条独立通知。
- 普通失败、自愈和自动重试不通知；若形成待我处理项，只发送该待办通知，不重复发异常通知。
- 通知支持两条路径：进入 App 定位原会话问题；或在系统通知内选择／文字直复。
- 打开 App 和锁屏直复需要系统生物识别；进入后，高风险操作不另加生物识别门槛。
- 多设备同时绑定并同步处理状态；任何手机不能撤销其他设备，设备撤销仅在电脑控制台本机管理入口。
- 锁屏显示项目、待办摘要和节点完成详情。

### 3.4 系统字体与触屏

- 字体跟随系统设置，使用原生字体度量，不以网页缩放代替。
- 原型提供 100%／130%／160% 检查档；正文、长问题、选项、输入框、产物文档、错误信息均参与缩放。
- 放大后采用换行、容器增高和纵向滚动；不截断、不遮挡、不把正文强制压成横向滚动。
- 图标视觉可以保持轻巧，但交互热区扩展至约 44–48 dp；整卡选项有清晰按压、选中和禁用状态。
- 适配安全区、系统返回、键盘升降、横竖屏与折叠／展开状态连续性。

## 4. 交互验收表（热区与返回路径）

| 来源 | 热区／触发 | 动作与目标 | 返回／异常 |
|---|---|---|---|

| 锁屏待办通知 | 通知主体 | 生物识别 → 会话内对应问题 | 已处理则显示最新状态 |
| 锁屏待办通知 | 选择／文字直复 | 生物识别 → 提交当前事项 | 失效不重复提交，草稿保留 |

| 阅读页 | 阅读／源码／HTML 标签 | 仅切换内容视图 | 保持文件与阅读位置 |

| 手机系统字体 | 系统设置，不需 App 内重复设置 | 全局文字和布局重排 | 极端字号仍允许纵向滚动 |

## 5. 视觉方向

- 延续控制台品牌绿、浅色底和卡片式信息架构。
- 以深墨绿作为关键行动和待办强调色，薄荷绿只作选中与状态底色。
- 采用细描边、轻阴影、充分留白和克制圆角，不使用装饰性大渐变。
- 会话、待回答组和产物文档以阅读层级优先，避免过多仪表盘式装饰。
- 参考 WorkBuddy 的“任务对话＋执行状态＋结果产物”连续路径，以及移动端底部导航、语音输入和结果验收方式；不照搬其品牌视觉。
