## 目标

总览「项目任务进度」不再「一个项目一条链/一个环」，改为：

1. 外层按**项目**分组；
2. 一个项目下挂 **1..N 条任务环**——**一个环 = 一条定义好的调度任务**，环内扇区 = 这条任务 DAG 设计里的节点（串行即一条链，并行即若干波次）；
3. **100% 完成**或**已取消**的任务环 → 归档，主视图只保留进行中的环；
4. 一个项目下所有环都归档 → 该项目整块不显示；归档的环收进底部「已归档的任务环」折叠区。

## 数据口径

| 项 | 来源 |
| --- | --- |
| 环（任务） | 串行链：`*-serial.json` 的 plan；DAG：`docs/dag-plans/<planId>.json`（任务定义） |
| 环内节点 | 该任务定义里的节点（`depends_on` / 并行组 / 波次） |
| 环的进度 | 该任务最新执行里各节点状态（done/dev/pending）折算百分比 |
| 同一任务多次运行 | 仍是一个环；run 只是执行记录，不单独成环 |
| 归档判定 | 全部节点 done（100%）或该任务所有 run 均已取消/放弃 |
| 归档可见性 | 主视图不显示；底部折叠区可展开查看 |

## 交互

- 点环 → 下方切换该环详情（当前节点、任务摘要、按波次的节点清单）。
- 归档区默认折叠，展开为紧凑条目（小环 + 任务名 + 完成度/取消 + 归档日期）。
- 串行任务与并行任务共用同一环；串行任务在详情里显示为单链节点序列。

## 验收

- `npm test`、`npm run test:browser` 全绿；
- 桌面 1440 / 移动 390 无横向溢出；
- 归档环不出现在主视图；全归档项目不显示；
- 项目内多环可切换、选中态与详情一致。
