## 目标与用户路径

- 目标用户：产品经理（本机控制台唯一用户）。
- 现有入口：Autoloop 控制台总览与会话工作区。
- 新会话统一进入“会话管理”；复杂需求经语义分类进入设计会话，再形成 PRD/Spec/DAG。
- DAG 与串行链在总览的“项目任务进度”中融合展示，使用同一套图形语言。

## 本轮确认的修订

### 0. 费用、Token 与节点上下文

- 每个项目直接展示今日费用、累计费用、今日 Token、累计 Token 及输入/输出拆分。
- 历史 DAG 条目直接展示该次运行费用与 Token，无需打开报告。
- 总览和运行详情的每个节点直接展示当前任务摘要、执行 Agent 与模型。
- 已完成节点展示实际执行过的 Agent/模型；待派发节点如实显示“待派发/模型待选择”，不编造。
- 节点详情侧栏同步展示当前摘要、Agent、模型、契约和证据。

### 1. 会话管理

- 保留原调度会话，新增普通会话与设计会话，统一为“会话管理”。
- 新建会话时，用 vibe-entry 改造版结合首句话语义推荐普通/调度/设计；允许手动覆盖。
- 普通会话：直接创建于项目工作区，不组装额外提示词，使用默认模式。
- 调度会话：保留现有调度提示词、Hub 状态读取与协调职责。
- 设计会话：原生 Codex Plan Mode + read-only，vibe 只负责规划与校验。
- 普通/调度/设计三个子 tab；左侧会话条目带项目名称和创建日期。**右侧会话界面直接遵循并复用当前 Codex App 会话界面的布局与交互，不另造对话体验；左侧管理界面采用本设计。**
- 会话支持折叠、归档、删除；删除必须二次确认，归档保留转录。
- 已完成历史任务和非活跃调度默认折叠，仍可查看，**不自动清理**。

### 2. 项目任务进度

- 串行与并行统一使用“分段环形总进度 + 节点卡片”，不再使用线性长条。
- 环形每个分段代表一个节点，中心显示整体完成度。
- 并行 DAG：颜色区分波次，深浅表达状态；节点按波次排列。
- 串行链：全部节点使用同一色相，深浅表达状态；节点按执行顺序排列。
- 阻塞保留琥珀色与图标，不只依赖颜色；所有节点均可点击进入详情。
- 历史 DAG 运行默认折叠、可查看，不自动清理。

其余 DAG 详情、接入预检、执行范围确认保持 R1 设计。

## 交互契约

| 来源 | 触发与命中区域 | 动作与目标状态 | 返回路径 |
| --- | --- | --- | --- |
| 总览 | “新建会话” | 打开会话管理与新建会话对话框 | 取消或关闭 |
| 新建会话 | 输入首句话 | 实时推荐普通/调度/设计并说明理由 | 可手动覆盖 |
| 新建会话 | “创建会话” | 在对应子 tab 创建并选中会话 | 右侧进入会话 |
| 会话管理 | 普通/调度/设计子 tab | 过滤并选择该类型的会话 | 再次点击其他子 tab |
| 会话列表 | 会话条目 | 右侧显示转录、模式、项目与输入区 | 点击其他会话 |
| 会话条目 | 折叠按钮 | 收起/展开条目摘要 | 再次点击 |
| 会话条目 | 归档按钮 | 移入“已归档与历史”，保留转录 | 历史区查看/恢复 |
| 会话条目 | 删除按钮 | 显示不可恢复的二次确认 | 取消或确认 |
| 已归档与历史 | 折叠标题 | 展开历史；只读查看，不自动清理 | 再次折叠 |
| 设计会话 | “确认执行范围” | 进入 PRD/DAG/授权确认 | 返回设计会话 |
| 授权确认 | 阅读勾选框 | 允许点击“确认并进入事件链” | 返回设计会话 |
| DAG 详情 | 任一节点卡片 | 右侧展示槽位、阶段、分支、契约和证据 | 选择其他节点 |
| DAG 详情 | “历史 DAG 运行” | 展开已完成运行并只读查看报告 | 再次折叠 |
| DAG 详情 | “取消运行” | 先等 run 终态，再 slot-release | 不直接清空槽位 |
| 接入预检 | 能力记录修复说明 | 显示真实 Codex 会话执行 vibe attest 的路径 | 留在预检页 |
| 所有新页面 | 右上角“页面状态” | 切换正常、空、加载、失败、阻塞说明 | 切回正常 |

空白区域不承载导航；所有按钮均为独立命中区域，没有整页点击或页面级热区。

## 状态与边界

- 空状态：没有会话或活跃 DAG，引导从新建会话开始。
- 加载中：保留最后成功内容，不清空界面。
- 加载失败：保留旧数据并允许重试，不把未知当完成。
- 阻塞：产品决策只阻塞相关节点，其他 ready 节点继续。
- 未勾选“我已阅读”时，授权主按钮禁用。
- 部署、发布、生产写入、其他凭据、对外通信和修改旧链始终排除。
- 历史任务与历史运行不做自动清理。
- 移动端导航与列表自身允许横向滚动，但页面主体无横向溢出。
