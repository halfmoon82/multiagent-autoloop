# Multiagent Autoloop 项目初始化设计

日期：2026-11-13
项目根目录：`/Volumes/Storage/auto调度`
公开仓库：`halfmoon82/multiagent-autoloop`

## 目标

把“评估 GitHub 项目改善跨平台自动化”会话中已经开发并正在 `127.0.0.1:50761` 运行的控制台，迁入独立、可持续维护的公开源码仓库；建立以 `AGENTS.md` 为项目记忆层的架构约束、Git/PR 闭环和可重复验证。

本项目是跨平台自动化的**控制面**：维护控制台、调度规则管理、事件链与调度事务。被调度的具体项目仍在各自隔离工作区开发，业务代码、运行状态和凭据不进入本仓库。

## 方案取舍

### 方案 A：忠实迁移 + 最小架构补齐（建议）

- 原样迁入当前控制台源码、测试和既有设计记录。
- 新增 `AGENTS.md`、架构/调度契约、`.gitignore` 和 GitHub Actions。
- 只修正项目身份、个人路径默认值和公开维护所需文档，不重写功能。
- 迁移后运行既有 23 项测试和浏览器回归，再通过 PR 独立审阅合并。

优点：保留已验证行为，变更最小，能清楚区分“历史成果迁移”和后续功能开发。

### 方案 B：把试点运行目录一并入库

不采用。试点目录包含 `master.key`、数据库、个人项目路径、平台命令和真实规则，会泄露凭据并把控制面与具体项目执行面耦合。

### 方案 C：迁移时重新设计控制台与调度内核

不采用。本轮目标是建立可靠源码基线，功能重构应另立需求、测试和 PR，避免无法区分迁移回归与新设计问题。

## `AGENTS.md` 必须固化的规则

1. **项目边界**：本仓库只拥有控制面；不得把被调度项目的源码、数据库、密钥或工作区状态提交到这里。
2. **上游边界**：记录 Agent Autoloop v1.8.1 本地化适配；上游修复与本项目扩展分开提交，不静默改写上游行为。
3. **调度职责**：调度方主动查看失败原因、修复可自愈的本地配置/脚本/规则并恢复执行；只有设计决策、外部授权、凭据、部署目标等门禁才请用户决策。
4. **事件链**：并行分支不得互为前提；部署结果不得阻塞开发调度；事件主题使用稳定 ASCII 标识，说明放 summary/detail。
5. **控制台信息**：运行、重试、今日完成、待调度处理各展示最近 5 条标题概要；条目和规则显示模型；完成项如实显示费用、Token 或“费用未上报”。
6. **隔离执行**：调度会话可在本项目创建，但具体任务必须在其目标项目隔离工作区执行；并行 AI 修改不得共享同一工作目录。
7. **安全**：默认只监听 `127.0.0.1`；密钥只在服务端；写操作保持同源、自定义头和 JSON 校验；公开前检查敏感信息。
8. **验证**：行为修改先写回归测试；提交前运行 `npm test`，UI/浏览器行为再运行 `npm run test:browser`；不得无证据宣称完成。
9. **Git/PR**：`main` 为稳定线，功能分支小步提交；PR 经独立 reviewer 按 P0–P3 审阅，P0–P2 清零且测试绿后 squash 合并；不直推主干，不自动部署。

## 公开仓库内容边界

入库：控制台源码、测试、通用文档、脱敏示例、CI。
不入库：`node_modules`、`.env`、`master.key`、SQLite/WAL、日志、真实 `rules.json`、个人绝对路径、真实项目截图、Codex 临时 `work/` 与 `outputs/`。

发现 `src/models.mjs` 使用 `<本机用户目录>` 作为 `HOME` 缺失时的回退值；迁移时改为跨平台中性回退，并补测试，避免把个人路径写入公开仓库。

## 验收标准

- 当前目录成为 Git 仓库，稳定分支为 `main`，功能分支承载本次初始化。
- 公开仓库 `halfmoon82/multiagent-autoloop` 创建成功并包含 `.gitignore`。
- 原控制台源码和调度要求完整迁入，无密钥、数据库、真实项目配置或个人路径。
- `npm test` 23 项基线及新增回归全部通过；Playwright 浏览器回归通过且不调用真实模型。
- GitHub Actions 可复现测试。
- 创建 PR，独立 reviewer 审阅；P0–P2 清零后 squash 合并到 `main`。
- 原 `50761` 服务不在迁移过程中被停止；是否切换到新目录运行另行验证，不与源码合并混为一步。

## 非目标

不部署、不发布 npm 包、不修改真实调度规则、不迁移具体健康项目、不新增远程访问、不重写 Autoloop 内核、不选择开源许可证。
